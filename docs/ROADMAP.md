## Сделать до того, как приложением начнут пользоваться другие

1. **Подготовка данных к синхронизации.** У каждой записи — время последнего изменения (`updatedAt`), удалённые записи помечаются (`deleted: true`), а не стираются. Нужна, чтобы потом объединять данные с двух устройств и резервные копии, а не заменять одно другим. Сделать сейчас: позже придётся писать миграцию для всех телефонов. Повысить `schema` до 2, миграция старых записей при загрузке.
2. **Страница конфиденциальности** `app/privacy.html`: данные только на устройстве, автор их не видит, контакт для вопросов. Ссылка с главного экрана.
3. **Подсказка для iPhone** при первом запуске в Safari: добавить на экран «Домой» и пользоваться с иконки.
4. **Объединение при загрузке копии** вместо полной замены (после пункта 1).
