Конфиденциальность

Ваши зарядки, пробег, расходы и напоминания хранятся только на вашем устройстве. Автор приложения их не видит: сервера, регистрации, рекламы и счётчиков посещений нет.

Где хранятся данные

Всё, что вы вводите, лежит в памяти браузера на этом телефоне. Приложение просит браузер не удалять эти данные, даже когда мало места.

Перед загрузкой копии или таблицы прежние данные откладываются там же, на телефоне, чтобы загрузку можно было отменить, — до следующей загрузки.

Что уходит в интернет

Ваши записи — никуда. Без интернета приложение работает полностью. В сеть оно обращается только за своими файлами (страницы, иконки, шрифт) и только к одному сайту:

файлы приложения раздаёт GitHub Pages. Как любой сайт, GitHub при этом видит IP-адрес и тип браузера (политика GitHub). К другим сайтам приложение не обращается.

Резервные копии

Файл копии создаётся на телефоне. Куда его отправить — в Telegram, на Диск или в «Файлы» — решаете вы, и дальше он хранится по правилам того сервиса. В файле все ваши записи, не пересылайте его посторонним.

Как удалить данные

В приложении: «Настройки» → «Удалить все данные». Сутки их ещё можно вернуть кнопкой «Вернуть как было», потом они стираются с телефона.

Чтобы не осталось совсем ничего, удалите приложение с главного экрана и очистите данные сайта в настройках браузера:

  • Chrome и Edge на Android: настройки браузера → «Конфиденциальность» → «Настройки сайтов» → «Все сайты» → этот адрес → «Удалить»;
  • iPhone: «Настройки» → «Приложения» → «Safari» → «Дополнения» → «Данные сайтов».

После этого данные не восстановить без резервной копии.
